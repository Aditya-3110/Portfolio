# Aditya Kumar Gupta Portfolio

This is an AI-assisted portfolio website created for Assessment Task 1 using
details from `Aditya_resume.pdf`.

## Included Sections

- Name and introduction
- Education
- Projects
- Technical skills
- Achievement
- Contact details

## How to Open

Open `index.html` in a browser to preview the website.

You can also run a local JavaScript server:

```bash
node server.js
```

Then open `http://localhost:8000`.

## How to Submit as a Live Link

Use any free static hosting option:

1. Netlify Drop: upload the project folder at `https://app.netlify.com/drop`
2. GitHub Pages: upload these files to a GitHub repository and enable Pages
3. Vercel: import the folder/repository and deploy it
